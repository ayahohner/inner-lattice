# Blog typefaces

Instrument Sans: complete variable WOFF2 files from [Instrument](https://github.com/Instrument/instrument-sans), preserving stylistic sets. Newsreader: Latin variable optical-size files from `@fontsource-variable/newsreader@5.3.0`. Both include their SIL Open Font Licenses.

The approved setting uses Newsreader 400 with 560 emphasis; Instrument Sans 580 headings and sets ss01, ss05, ss06, ss10, ss11, ss12. Optical sizing is automatic. Code continues to use the existing JetBrains Mono dependency.
